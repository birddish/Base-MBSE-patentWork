# 机械论证模式

有选择地使用以下模式。当事实不支持时，不要强行套用论证模式。

## 1. 一体化机械配合

当多个权利要求特征配合以实现一个机械效果时使用。

模式：

> 区别技术特征并非彼此独立的零部件替换，而是通过……位置关系/连接关系/运动关系共同形成……技术手段。若将其中任一特征脱离其他特征单独评价，将无法实现……技术效果。

配合示例：

- 导轨 + 滚轮朝向 + 间隙；
- 机架路径 + 铰接单元 + 驱动接触面；
- 密封圈 + 压缩方向 + 限位台肩；
- 弹簧 + 锁止件 + 调节路径；
- 驱动轴 + 偏心件 + 连杆臂。

## 2. 对比文件不兼容

当两篇对比文件在不改变其结构或原理的情况下无法组合时使用。

分析要素：

- 结构前提：所需形状、位置、接触面、安装位置或接口；
- 功能前提：该结构被设计用于实现什么功能；
- 行为前提：运动方向、顺序、施力点或约束关系；
- 组合后果：干涉、失去接触、失去支撑、改变受力路径或破坏原有目的。

模式：

> 对比文件A的……要求……，而对比文件B的……以……为前提。将B的结构应用于A时，会导致……，从而破坏A原有的……工作方式。本领域技术人员没有动机作出该组合。

## 3. 受力路径与运动路径区别

当发明在力或运动的传递方式上存在区别时使用。

检查要点：

- 拉 vs 推；
- 直接驱动 vs 间接邻接单元传递；
- 点接触 vs 面接触；
- 滚动接触 vs 滑动摩擦；
- 轴向力 vs 径向力；
- 转动转平动或平动转转动；
- 连续驱动 vs 间歇/离散啮合。

模式：

> 本申请中，力由……经……传递至……，使……产生……运动；而对比文件中，力由……作用于……，未直接受力部分主要通过……传递。因此二者的受力路径和运动行为不同，并非等同替换。

## 4. 尺寸、节距、间隙与接口约束

当现有技术受尺寸、节距、间距、齿啮合、孔、槽或安装接口约束时使用。

常用机械约束：

- 齿轮齿距 / 链条节距 / 拨爪间距；
- 螺栓孔间距 / 槽长 / 铰链位置；
- 导向间隙 / 滚轮直径 / 轨道宽度；
- 密封压缩量 / 槽深；
- 轴承座接口 / 轴径；
- 模数、齿条节距、凸轮轮廓、偏心距。

模式：

> 对比文件的……需要与……尺寸/节距/间隙相匹配，因此其结构尺寸不能脱离该匹配关系任意改变。该约束使其无法自然得到本申请中……的结构。

对于推断的"更大/更小"设计优势，除非权利要求明确限定，否则不要说权利要求限定了某个尺寸。推荐表述：

> 权利要求中的……提供了形成/适配……尺寸或界面的结构基础。

## 5. 传统替代方案仍不成立

当审查员或现有技术提出惯用替代方案（如以皮带替代齿轮、以滚动替代滑动、增加弹簧或使用已知紧固件）时使用。

模式：

> 即使采用……传统替代方式，也只能改变……，并不能改变……这一导致技术问题的根本结构关系。因此，该替代方式不能自然解决本申请实际解决的技术问题。

示例：

- 对短节链条增加摩擦驱动并不能改变短节链收敛几何关系；
- 以弹簧替代刚性支撑并不能形成权利要求所述的锁止顺序；
- 将导向从滑动改为滚动并不能形成权利要求所述的双轴导向关系；
- 增加密封件并不能形成权利要求所述的压缩方向与限位关系。

## 6. "先有结构需求，再选择驱动/控制方式"

当审查员颠倒了发明的因果关系时使用。

模式：

> 本申请的技术路线并非先任意选择……驱动/控制方式，再得到……结构；而是由于……工况首先需要……结构，在该结构形成后，传统……方式不再适配，才进一步采用权利要求中的……方式。

适用场景：

- 板链 + 摩擦驱动；
- 大工件 + 非齿轮驱动；
- 柔性密封 + 限位/压缩结构；
- 不规则导向路径 + 多向滚轮；
- 重载支撑 + 分散驱动。

## 7. MBSE 到意见陈述书的转换

当存在 MBSE 分析时，进行如下转换：

- 需求 → 实际解决的技术问题；
- 功能 → 特征的技术作用；
- 结构 → 权利要求特征及支持依据；
- 行为 → 工作过程/受力路径/运动路径；
- 效果 → 技术效果。

不得在最终意见陈述书中保留 R1、F2、S3 或 B4 等 MBSE 标注符号。
