# 生化/材料域论证模式

有选择地使用以下模式。当事实不支持时，不要强行套用论证模式。

## 1. 组分不兼容

当 D1 的组合物体系与 D2 教导添加的组分在化学上不兼容时使用。

**分析要素**：
- D1 的体系特性：酸性/碱性、氧化/还原、水性/油性、极性/非极性；
- D2 添加组分的化学性质：反应活性、稳定性条件、配伍禁忌；
- 组合后果：沉淀、分解、失效、产生有害副产物。

**模式**：
> D1 的组合物以 [体系特性] 为基础/前提，而 D2 教导添加的 [组分] 在 [该体系特性] 下会 [发生不利反应/降解/失活]。因此，本领域技术人员不会将 D2 的教导应用于 D1 的组合物中——这违背了保持组合物稳定性和有效性的基本常识。

**示例**：
- D1 的组合物需在酸性条件下稳定，D2 教导添加碱性组分 → 酸碱中和，组合物失效；
- D1 为水性乳剂，D2 的活性成分在水中水解 → 不能共存；
- D1 含氧化剂，D2 的组分为还原性物质 → 发生氧化还原反应。

## 2. 工艺条件冲突

当 D1 的方法所需工艺条件与 D2 教导的工艺条件不可调和时使用。

**分析要素**：
- D1 的工艺条件：温度、时间、压力、pH、溶剂、催化剂；
- D2 的工艺条件要求；
- 冲突性质：互斥的温度区间、不兼容的溶剂体系、催化剂中毒、反应选择性丧失。

**模式**：
> D1 的方法在 [工艺条件 A] 下进行，而 D2 教导的 [操作/组分] 在 [工艺条件 A] 下 [失效/失活/产生副反应]。将 D2 的教导引入 D1 的方法，需要同时改变 D1 的工艺条件，但改变工艺条件将导致 D1 原有技术效果 [丧失/劣化]。因此，二者无法在同一工艺中共存。

**示例**：
- D1 反应在 150°C 进行，D2 的催化剂在 120°C 以上分解；
- D1 使用有机溶剂，D2 的酶催化剂在有机溶剂中变性；
- D1 需在 pH 2 下反应，D2 的中间体在酸性条件下降解。

## 3. 参数范围非显而易见

当审查员认为本申请选择的参数范围属于"常规优化"或"有限次实验可得"时使用。

**分析要素**：
- 本申请选择的参数范围；
- 对比文件公开的参数范围或教导的参数方向；
- 本申请范围带来的技术效果（需有对比例或实验数据支撑）；
- 对比文件是否给出了选择本申请范围的启示。

**模式**：
> 本申请选择的 [参数] 范围 [a-b] 并非对比文件公开范围的简单缩小或本领域的常规选择。对比文件 D1 教导的参数范围为 [c-d]，其优选方向为 [方向]。本申请的范围 [a-b] 与 D1 的教导方向 [一致/相反]，且在该范围内取得了 [具体效果]。该效果无法从 D1 或本领域常识中合理预期，本领域技术人员没有动机在 D1 的基础上通过"常规实验"得到本申请的范围。

## 4. 反向教导

当 D2 明确教导避免使用某种组分、条件或方式时使用。

**分析要素**：
- D2 的明确教导内容（引用原文）；
- 审查员主张的应用方向；
- D2 的教导与审查员主张方向的矛盾。

**模式**：
> D2 明确教导"[引用 D2 原文]"，即本领域技术人员在面对 [场景] 时应 [避免/不采用] [某方案]。审查员主张将 D2 的教导以相反方向应用于 D1，这与 D2 自身的技术教导直接矛盾。本领域技术人员在阅读 D2 后，不会违背其明确教导而进行方向相反的操作。

## 5. 协同效应与效果不可预期

当组合产生了超出各组分单独效果的协同效应时使用。需要有实验数据支撑。

**分析要素**：
- D1 单独的效果；
- D2 单独的效果；
- 组合后的实际效果；
- 效果的叠加性 vs 协同性。

**模式**：
> 将 D2 的 [组分/条件] 引入 D1 后，产生的 [效果] [大于/不等于] D1 单独效果与 D2 单独效果的 [简单叠加]。这种协同效应（或新效果）无法从 D1 或 D2 的单独公开中合理预期。本领域技术人员在阅读 D1 和 D2 后，无法预见到该组合会产生上述协同效应，因此不存在进行该组合的技术启示。

## 6. Markush 权利要求的非显而易见性

当审查员认为 Markush 权利要求中的某选择被对比文件公开或属于常规选择时使用。

**分析要素**：
- Markush 通式的范围；
- 本申请具体选择的要素；
- 对比文件公开的要素；
- 本申请选择带来的技术效果。

**模式**：
> 虽然 D1 公开了通式 [X]，但本申请从该通式涵盖的众多可能中具体选择了 [要素 Y]，该选择并非 D1 的优选方案或具体实施例。更重要的是，选择 [要素 Y] 带来了 [具体技术效果]，该效果无法从 D1 的通式教导中合理预期。本领域技术人员在 D1 的通式范围内，没有动机特别选择 [要素 Y] 并预期其会带来上述效果。
