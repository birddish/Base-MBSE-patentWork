# MBSE 建模失败模式（全 Mode 通用）

在定稿任何阶段产出物或最终报告之前，使用本清单检查。本文件合并自 disclosure 和 document 两种场景的常见失败模式。

---

## 一、硬失败（任一命中即阻断通过）

### 证据与文件

- 将两份文件混入一个模型，未使用独立前缀
- 将 Q 节点用作事实前提
- 用常识或另一份文件的公开内容替代缺失的公开内容
- 将申请文件公开内容、现有技术或对比文件混合到一个未标记的模型中
- 将附图外观视为明确公开，但附图存在歧义

### 模型结构

- 将组件列表当作结构模型，缺少接口或分配关系
- 输出流程图但没有追溯矩阵（document mode）
- 将技术效果当作需求，然后使用相同的措辞作为最终效果
- 将F、F.Output或STATE.OutputState换词复制为E，形成同义反复闭环
- E与F使用相同动作和对象，E没有受影响属性或进一步技术后果
- E仅写“实现了F”，或者脱离S/B/关系/CV因果来源仍被宣称成立
- 比较型或定量E缺少比较基线、共同条件、测量口径或证据
- 输出没有行为链条的创新点（disclosure mode）
- 将 C/P 节点直接保留在模型中而未映射至 R/F/S/B/E

### 法律边界

- 撰写新颖性、创造性、侵权或权利要求覆盖范围等法律结论
- 在实际检索或对比之前写出"专利库空白""具备新颖性"或"具备创造性"
- 在实际检索之前将差异化假设写成检索结论

### 数据与图表

- 推测文本中不存在的数值、阈值、尺寸、材料、算法、协议字段或化学范围
- 生成的 Mermaid 图表节点 ID 与模型表格不匹配
- 生成的 JSON 包含 Markdown 注释、尾部逗号或机器可读代码块外有叙述性文字

## 二、软失败（降低模型质量，但不阻断通过）

### R（需求）层面

- R 重复了技术效果，而非陈述需求/约束
- R 使用了模糊的商业目标（如"提高效率""降低成本"）替代技术问题
- R 未以"如何……"开头

### F（功能）层面

- F 使用模糊动词如"处理""优化""管理"，缺少输入/输出
- F 没有分配的实现结构（S）
- F 缺少触发条件或守卫
- F 缺少输入、技术变换或直接输出，或者预先绑定唯一实现结构而没有必要依据

### S（结构）层面

- S 使用泛指的"模块"标签，缺少实现关系
- S 是一个裸特征列表，没有功能分配或接口
- S 缺少与其他 S 节点的连接/接口关系

### B（行为）层面

- B 仅复述方法步骤，省略触发条件、守卫、状态或异常路径
- B 缺少操作顺序、控制条件、反应/工艺路径或消息流
- B 将正常路径与异常/失败/超时路径混在一起

### E（效果）层面

- E 将"降低人工成本"等商业利益当作技术效果，但没有技术机理
- E 缺少与 B/S 的追溯关系
- E没有说明受影响对象、属性、适用条件或从OutputState到后果的路径
- 比较型E虽有方向性结论，但没有明确比较基线、共同条件或证据

### 检索与创新点（disclosure mode）

- 提出通用的发明人问题，但未指明缺失的 R/F/S/B/E 维度
- 过度扩展检索词，使用"系统""装置""计算机""方法"等通用词语
- 将 IPC 候选分类号当作权威分类

### 跨文件（document mode）

- 对照表反向修改了单文件模型
- 将"未公开"表述为"不可实现"
- 审查员逻辑映射缺少对应的模型节点

## 三、修复措施

| 失败类型 | 修复措施 |
|---------|---------|
| 混合文件模型 | 拆分为独立前缀的模型（AP、D1、D2） |
| Q 节点作前提 | 将无依据的事实转换为 Q，并拟定确认问题 |
| 缺少接口 | 为每个物料流/数据流/控制流添加接口卡片 |
| F 无分配 S | 添加从 F 到 S 的 allocate 行 |
| R/E 重复 | 将R重写为技术需求或约束，将E重写为由具体因果链产生的技术后果 |
| F/E或输出/E重复 | 将输入—变换—直接输出保留在F/STATE，继续追问受影响对象和属性；无进一步后果时删除E或标Q |
| S 裸列表 | 添加分配和接口行，或将缺失的接口标注为 Q |
| B 缺失 | 询问操作顺序、控制条件、反应/工艺路径或消息流 |
| 新颖性表述过强 | 降级为"待检索验证"或"初步差异假设" |
| 图表表格不一致 | 根据表格更新图表，而非反过来 |
| 法律措辞越界 | 将所有法律措辞降级为技术对应关系或证据覆盖说明 |
| C/P 节点未映射 | 将 C 映射至 S（接口结构）或 B（交互行为）；将 P 映射至 R（约束需求）或 E（数值效果） |
