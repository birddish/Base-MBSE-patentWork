# 权利要求布局指南

## 布局基本原则

### 独立权利要求的定位

独立权利要求应覆盖技术方案最核心的**完整追溯链**：
- 至少包含一个需求对应的核心功能
- 包含实现该功能的必要结构特征
- 包含体现发明点的关键行为特征（如时序、条件）
- 避免写入非必要限定（留给从属权利要求）

### 从属权利要求的层级设计

```
独立权利要求（核心追溯链）
├── 从属权利要求 2：结构细化层（S3、S4 的具体化）
│   ├── 从属权利要求 3：引用权2，进一步结构限定
│   └── 从属权利要求 4：引用权2，替代结构方案
├── 从属权利要求 5：行为补充层（B2、B3 的补充）
│   └── 从属权利要求 6：引用权5，条件细化
└── 从属权利要求 7：效果增强层（附加技术效果）
```

**层级设计原则**：
- 按创新点层次展开，非随机排列
- 同一层的从属权利要求应平行并列
- 下位从属应进一步限定而非重复上位

## 常见布局模式

### 模式一：单核心多维度展开

适用于：一个核心技术方案，从多个维度展开保护

```
权1（独立）：核心方法/装置 — 包含 S1、S2、B1
权2（引权1）：限定 S1 的具体实现方式 A
权3（引权1）：限定 S1 的具体实现方式 B（替代方案）
权4（引权1）：限定 S2 的结构细节
权5（引权1）：限定 B1 的时序细节
权6（引权1）：增加 B2（附加步骤）
权7（引权1）：增加 S3（附加组件）
```

### 模式二：多核心并列

适用于：技术方案包含多个相对独立的发明点

```
权1（独立）：核心方案 A — S1+S2+B1
权2（引权1）：方案 A 的细化
...
权N（独立）：核心方案 B — S3+S4+B2（与方案 A 可独立实施）
权N+1（引权N）：方案 B 的细化
...
```

**注意**：多独立权利要求之间应评估是否满足单一性要求。

### 模式三：双轨保护（方法+装置）

适用于：技术方案既涉及方法步骤又涉及装置结构

```
权1（独立）：方法权利要求 — B1+B2+...
权2（引权1）：方法细化
...
权M（独立）：装置权利要求 — S1+S2+...（与方法对应）
权M+1（引权M）：装置细化
...
```

## 布局与创新点的映射

| 创新点类型 | 布局策略 |
|-----------|---------|
| 结构创新 | 独立权利要求包含基础结构，从属权利要求展开结构细节和替代方案 |
| 功能创新 | 独立权利要求突出功能限定，从属权利要求限定实现该功能的具体手段 |
| 行为创新 | 独立权利要求包含关键步骤/时序，从属权利要求补充条件、参数、异常处理 |
| 协同创新 | 独立权利要求保留产生协同效果的必要组合，从属权利要求分别展开各组成部分 |

## 布局建议输出模板

```
【权利要求布局建议】

=== 独立权利要求 1 ===
建议类型：[方法/装置/系统]
保护主题：[一句话概括]

必备特征（应写入权1）：
1. [结构特征 S1]：...（解决核心问题的必要结构）
2. [结构特征 S2]：...（与S1协同的必要结构）
3. [行为特征 B1]：...（体现发明点的关键步骤/时序）

建议撰写顺序：
1. 先写主题名称
2. 再写 S1+S2 的结构限定
3. 最后写 B1 的行为限定

可选特征（建议留至从属权利要求）：
- S3 的具体实现细节
- B2 的附加步骤
- 参数具体数值

=== 从属权利要求 ===

层级一：结构细化
- 权2（引权1）：限定 S1 为 [具体形式 A]（对应创新点 X）
- 权3（引权1）：限定 S1 为 [具体形式 B]（替代方案）
- 权4（引权1）：限定 S2 的 [连接方式/位置关系]

层级二：行为补充
- 权5（引权1）：增加 B2 — [附加步骤]（对应创新点 Y）
- 权6（引权5）：限定 B2 的 [执行条件/参数]

层级三：效果增强
- 权7（引权1）：增加 S3 — [附加组件]，用于 [增强效果]

=== 多组权利要求评估 ===
是否需要并列独立权利要求：[是/否]
理由：...

=== 待发明人确认事项 ===
- [?] S1 的具体材质是否影响保护范围？
- [?] B1 中的参数 X 是否有替代范围？
```

## 注意事项

- **上位与下位的平衡**：独立权利要求用上位概念争取宽保护，从属权利要求用下位概念确保稳定性
- **单一性检查**：多组独立权利要求之间应有相同或相应的特定技术特征
- **支持问题**：权利要求中的每个特征应在交底书（或预期撰写的说明书）中找到支持
- **清楚完整**：独立权利要求应构成完整的技术方案，从属权利要求应进一步限定而非引入新方案
