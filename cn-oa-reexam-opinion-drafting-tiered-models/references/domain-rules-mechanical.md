# 机械/结构域撰写规则（审查意见答复）

## 规则说明

本文件为机械/结构领域审查意见答复和复审意见陈述书的域特定撰写规则。提取自原机械 skill 的撰写规则并独立成文。

## 机械域 S 节点类型与建模

### S 节点分类

机械域的权利要求 S 节点（技术特征）主要分为以下类型：

| S 节点类型 | 含义 | 审查意见中的典型争议 |
|-----------|------|-------------------|
| 构件 | 零件、部件、组件等物理实体 | 对比文件是否公开了该构件 |
| 连接关系 | 固定连接、活动连接、铰接、焊接、螺纹连接等 | 连接方式是否为惯用替换 |
| 配合关系 | 间隙配合、过盈配合、过渡配合、啮合、贴合等 | 配合关系是否被对比文件公开或暗示 |
| 位置关系 | 上下、内外、前后、同轴、平行、垂直等空间关系 | 位置关系是否为常规布置 |
| 运动关系 | 转动、平动、摆动、往复运动、行星运动等 | 运动方式是否为等效替换 |
| 尺寸/参数 | 长度、角度、间隙、节距、模数等 | 参数是否为常规设计选择 |

## 机械域特有撰写规则

### 权利要求特征类型

- **产品权利要求**优先采用：结构特征、连接关系、位置关系、配合关系
- **方法权利要求**优先采用：装配步骤、加工步骤、操作步骤
- 禁止功能性限定，除非结构特征无法表达且说明书有充分支持

### 独立权利要求架构

- 必含：基础构件 + 特征性构件 + 连接/配合关系
- 连接关系写明：固定连接/活动连接/传动连接 + 连接方式 + 相对位置
- 避免：仅用功能描述构件（如"固定装置"），须有结构基础

### 从属权利要求分层

推荐层次：核心结构 → 连接细化 → 材料/尺寸 → 附加功能件。每层增加一个可识别的结构特征，对应一项技术效果。

### 实施方式

- 结构主实施例 + 至少一个变体实施例
- 必须描述装配关系或运动关系
- 附图标记与特征逐一对应

## 机械域核心撰写规则

- 以权利要求区别特征及其机械功能为中心展开论证，而非逐文件批评。
- 在使用任何决定性命题之前，执行证据关卡。区分"未公开/未给出技术启示"与更强的结论"无法实现"；仅在有物理约束及其证据基础的前提下使用后者。
- 解释结构如何运作：相对位置、连接、运动、力传递、约束、接触、变形、密封、导向或装配顺序。
- 对于受力路径论证，识别主动力源、接触或啮合区域、直接驱动单元、间接驱动单元、单元间传递路径、约束反力及运动结果。不要将视觉上的相似性等同于相同的受力路径。
- 除非说明书明确支持，否则不要将仅基于附图的推论作为权利要求限定。
- 不要将未要求保护的参数（如"大""小""长"或"高摩擦"）转化为明示的权利要求限定。在有支持的情况下，将其描述为结构能力、适配空间或技术趋势，而非断言性数值事实。
- 对推断性优点使用审慎措辞："提供……结构基础""适于……""能够减少/避免……"，而非无支持的绝对效果。

## 机械域论证措辞规则

- 一体化机械配合论证："区别技术特征并非彼此独立的零部件替换，而是通过 [位置关系/连接关系/运动关系] 共同形成 [技术手段]。若将其中任一特征脱离其他特征单独评价，将无法实现 [技术效果]。"
- 对比文件不兼容论证："对比文件 A 的 [结构] 要求 [条件]，而对比文件 B 的 [结构] 以 [不同条件] 为前提。将 B 的结构应用于 A 时，会导致 [干涉/失去接触/改变受力路径/破坏原有功能]。"
- 受力路径论证："本申请中，力由 [主动力源] 经 [传递路径] 传递至 [被驱动件]，使 [被驱动件] 产生 [运动]；而对比文件中，力由 [另一路径] 传递，未直接受力部分主要通过 [其他方式] 传递。因此二者的受力路径和运动行为不同。"
- 尺寸/节距约束论证："对比文件的 [结构] 需要与 [配合件] 的 [尺寸/节距/间隙] 相匹配，因此其结构尺寸不能脱离该匹配关系任意改变。该约束使其无法自然得到本申请中 [更大/更小/不同] 的结构。"

## 常见陷阱

- [ ] 不要将仅基于附图的推论作为权利要求限定——附图是示意性的，尺寸比例不可作为限定依据
- [ ] 不要将未要求保护的参数转化为明示的权利要求限定——"大""小""高""低"等如未在权利要求中明确记载，不得作为区别特征
- [ ] 注意 "可以做大的" 措辞——当权利要求未明确记载尺寸时，使用"提供形成较大……的结构基础"而非"权利要求限定了较大尺寸"
- [ ] 注意一体化机械配合——多个特征配合实现一个效果时，应作为整体评价，而非逐一孤立分析
