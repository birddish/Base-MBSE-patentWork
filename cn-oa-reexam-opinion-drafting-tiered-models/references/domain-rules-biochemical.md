# 生化/材料域撰写规则（审查意见答复）

## 规则说明

本文件为生化/材料领域审查意见答复和复审意见陈述书的域特定撰写规则。源自 `cn-patent-drafting-workflow` 的 `domain-rules-biochemical.md` 并适配至审查意见答复场景。

## 生化域 S 节点类型与建模

### S 节点分类

生化域的权利要求 S 节点（技术特征）主要分为以下类型：

| S 节点类型 | 含义 | 审查意见中的典型争议 |
|-----------|------|-------------------|
| 组分 | 组合物中的必要组分、可选组分 | 对比文件是否公开了该组分 |
| 含量范围 | 各组分的重量份、质量百分比、摩尔比 | 范围是否被对比文件公开或为常规优化 |
| 工艺步骤 | 制备/合成方法的步骤顺序 | 步骤顺序是否可调整 |
| 工艺条件 | 温度、时间、压力、pH、催化剂等 | 条件是否为常规选择 |
| 结构特征 | 化合物通式、取代基、Markush 要素 | 是否被对比文件具体公开 |
| 性能参数 | 粘度、分子量、纯度等 | 参数是否为固有属性 |

### 建模特别要求

- 对组合物权利要求，为每个必要组分建立独立 S 节点，标注含量范围；
- 对制备方法权利要求，将步骤顺序作为 B 节点的序列关系；
- 区分"开放式表述"（包含/包括）和"封闭式表述"（由……组成），在 E 节点中标注表述类型对保护范围的影响；
- 对 Markush 权利要求，将各可选要素作为 S 节点的可选属性。

## 生化域审查意见常见问题

### 新颖性问题

- 对比文件公开了通式化合物，本申请为具体化合物 → 论证具体化合物的选择并非简单选择，具有预料不到的技术效果
- 对比文件公开了组合物但未公开某组分的含量 → 论证含量范围带来了预料不到的效果，非本领域常规优化
- 对比文件为产品权利要求，本申请为用途权利要求 → 区分产品与用途的不同保护客体

### 创造性问题

- **组分不兼容**：D1 的组合物需要酸性环境，D2 教导添加碱性组分 → 二者在化学上不兼容
- **工艺条件冲突**：D1 的反应需在 100°C 进行，D2 的催化剂在 100°C 失活 → 不能简单组合
- **反向教导**：D2 明确教导避免使用某种组分/条件 → 构成反向教导
- **效果不可预期**：组合后产生的协同效应或新效果无法从单个文件预期
- **参数范围选择**：本申请选择的特定参数范围带来了预料不到的技术效果，非本领域常规实验

## 生化域特有撰写规则

### 产品权利要求（组合物）

- 必含：必要组分 + 含量范围
- 开放式/封闭式表述选择：
  - "包含"（开放式，允许其他组分）
  - "由……组成"（封闭式，排除其他组分）
  - "基本上由……组成"（仅允许不影响基本特性的杂质）
- 含量单位统一：重量份、质量百分比或摩尔比
- 在审查意见答复中，如修改了含量范围，须有原申请文件的端点实施例支持

### 方法权利要求（制备/合成）

- 步骤顺序 + 工艺条件（温度、时间、压力、pH、催化剂等）
- 原料配比与产物对应关系
- 必要时包含纯化/后处理步骤
- 在答复中论证步骤顺序的非显而易见性时，说明改变顺序会导致不同产物或降低收率

### 用途权利要求

- 基于产品特征的用途限定
- 格式示例："化合物 X 在制备治疗 Y 的药物中的用途"
- 注意与 Swiss 型权利要求的区别

### 参数限定

- 参数限定的测量方法应在说明书中明确记载
- 不同测量方法得到不同数值时，须以说明书记载的方法为准
- 参数范围端点值须有实施例支撑

## 生化域论证措辞规则

- 组分之间的相容性论证："D1 的组合物要求 [条件 A]，而 D2 教导添加 [组分 B] 在 [条件 A] 下会 [发生不利反应/分解/失活]，因此本领域技术人员不会将 D2 的教导应用于 D1。"
- 工艺条件冲突论证："D1 的反应在 [温度 T1] 进行，而 D2 的催化剂在 [温度 T1] 下 [失活/分解/选择性降低]，二者无法在同一工艺中共存。"
- 效果不可预期论证："将 D2 的组分引入 D1 的组合物后，产生的 [协同效应/新效果] 无法从 D1 或 D2 的单独公开中合理预期。"
- 参数范围非显而易见："本申请选择的 [参数] 范围 [a-b] 并非本领域的常规选择，该范围带来了 [具体效果]，超出了本领域技术人员的合理预期。"

## 常见陷阱

- [ ] 不要将组合物中各组分的含量简单相加得出"公开了该组合物"的结论——各组分的组合可能产生新的化学实体
- [ ] 不要仅凭组分名称相同就认定公开——组分的结构、纯度、来源不同可能导致技术效果差异
- [ ] 注意 Markush 权利要求的单一性——修改时避免加入互不相关的替代方案
- [ ] 注意实验数据的必要性——声称预料不到的技术效果须有实验数据（实施例/对比例）支撑
